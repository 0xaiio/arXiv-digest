# 日常使用

假设流水线已经跑过（见 [快速开始](../getting-started/quickstart.md)）。本文按"一次完整的日常使用"
组织：进来做什么、怎么筛、怎么留下来、怎么回看。

---

## 一、一天的使用节奏

```
早上或固定时间：python run_daily.py        # 抓取 + 打分 + 渲染 + 起服务
打开 127.0.0.1:8765                        # 端口被占用时会顺延，以日志里 serving 那行为准
├─ 先扫「为你推荐」（14 篇，按分数降序）       → 收藏 / 下载决定看什么
├─ 再扫「兴趣扩展」（10 篇，邻域论文）        → 打破茧房
└─ 有精力再看「分类详解」                     → 按分类翻本期全部新增
```

推荐的排序会随你的点击实时变化，所以**先点后看**比"从上往下读完再动手"效率更高：
收藏一篇强相关论文，会把同类主题的其它论文一起顶上来。

## 二、三个板块怎么读

| 板块 | 只包含 | 不该期待 |
| --- | --- | --- |
| 🎯 为你推荐 | 主分类（`config.categories`）里本期新增、分数 ≥ 7 的前 N 篇 | 不会包含扩展分类的论文 |
| 🌱 兴趣扩展 | 扩展分类（`config.expand_categories`；留空时自动取同 archive 的兄弟分类）里本期新增、分数 ≥ 9 的前 N 篇 | 阈值更严，宁缺勿滥；出现在主分类 feed 里的论文会被按短号严格排除，不会两边都出现 |
| 📖 分类详解 | 本期**全部**新增论文 | 不做质量筛选，只按分类/日期排列 |

每张卡片上的信息各有用途：

| 元素 | 含义 |
| --- | --- |
| 编号 `01` `02` | 当前位置（重排后会重新编号，不是论文 ID） |
| 评分 | 打分结果，保留一位小数；分数构成可在 [排序算法](../architecture/ranking.md) 里对上 |
| 命中主题 | 这篇命中了画像里的哪几个主题（最多显示 4 个） |
| 熟悉作者高亮 | 作者列表里出现 `interests.people` 中的名字 |
| 推荐理由 | 默认取命中主题；可以在 `output/rec_notes.json` 里按短号覆盖为人工点评 |
| 作者单位 | 由 `fetch_affil.py` 从 arXiv HTML 解析，命中率不保证 100% |

## 三、工具栏

工具栏固定在页面顶部，负责"筛选 + 导航"：

| 控件 | 行为 |
| --- | --- |
| 全部 / 已收藏 / 已下载 / 已 Downvote | 按状态筛选。**作用范围是「📖 分类详解」列表**（不含两个推荐板块）；Downvote 一项会同时显示灰色卡片，便于撤销误点 |
| 搜索框 | 在「分类详解」列表里做即时过滤（前端本地匹配 `textContent`，不发请求） |
| 批量下载 | 把两个推荐板块里**当前可见、未被 Downvote** 的卡片一次性下载（最多 `DL_WORKERS=3` 路并发，顺序与列表一致）。分类详解不受此按钮影响 |
| ↻ 重算推荐 | 后台重跑 `recommend.py` + `build_report.py`，用于改完画像后立即生效 |
| 往期回看 | 跳到 `/archive` |
| ⚙ 画像与设置 | 跳到 `/profile` |

## 四、五个按钮各自触发什么

按钮不只是 UI 动作，每一次点击都会回传服务端并更新画像（弱→强排序）：

| 按钮 | 服务端接口 | 副作用 |
| --- | --- | --- |
| 收藏 | `POST /api/favorite` | 写入 `library.json`；若该篇被 Downvote 过则自动撤销；正向学习（1.0） |
| 已收藏（再点） | `POST /api/unfavorite` | 移出收藏；反向学习（-0.7，较弱） |
| 下载 | `POST /api/download` | PDF 存入 `download_dir`，**自动收藏**；正向学习（1.3，最强） |
| Abstract | `POST /api/event` `action=abstract` | 就地展开摘要；弱正向（0.3） |
| PDF | `POST /api/event` `action=pdf` | 新窗口打开 arXiv PDF；中弱正向（0.55） |
| Downvote | `POST /api/downvote` | 该篇固定 -12 分并变灰划线；**不改写全局主题权重** |
| 已 Downvote（再点） | `POST /api/undownvote` | 撤销 -12，恢复排序 |

学习强度可以在 `interests.json` 的 `behavior.actions` 里改，见
[interests.json 参考](../reference/interests.md)。

## 五、收藏与导出

打开 `/favorites`（工具栏计数可点）：

- 列表按收藏时间倒序，带标题、分类、日期、评分、本地 PDF 路径；
- **⬇ 导出清单 (.md)** 会下载 `favorites.md`，内容为 Markdown 列表，适合贴进周报或文献笔记；
- 取消收藏直接在列表里点按钮，与日报页共享同一份 `library.json`。

> 收藏是"想读/读过"的语义，不是"已归档"。真正的长期文库是 `download_dir` 里的 PDF 文件本身，
> 命名规则固定为 `arXiv<年> <短号> <去标点标题>.pdf`，见
> [数据文件](../reference/data-files.md)。

## 六、回看往期

`/archive` 按日期列出每一期，点进去是当期快照（原样保存，不会被后续重跑改写）。

两条容易混淆的规则：

1. **日报只呈现本期新增**。同一篇论文不会在第二天的日报里再出现一次（这是"累积池 + `seen` 表"
   的判定结果，见 [架构总览](../architecture/overview.md)）；
2. **同日重复跑是幂等的**。当天再跑一次流水线，`seen` 里首次期次就是本期的论文仍算本期，
   不会把页面清空。

所谓"今天"指 `output/arxiv_digest_<日期>.html` 中日期最新的那一份，`/` 永远打开它；
想临时看某一期，用 `/archive/<YYYYMMDD>` 或 `/?f=arxiv_digest_<YYYYMMDD>.html`。

## 七、离线使用

日报是**自包含单文件 HTML**（内联 CSS/JS，无外部 CDN）。用 `file://` 直接双击打开也能看：

- 阅读、搜索、筛选、展开摘要都可用；
- 收藏 / 下载 / Downvote 会请求 `http://127.0.0.1:8765`，所以**服务必须在跑**；
- 页面里的站内链接会自动改写为绝对地址，跨源请求由服务端 CORS（`*`）放行。

## 八、效率建议

- 每天只做两件事：**收藏**当天要读的、**Downvote**明显不相关的。前者提升同类，后者精确排除单篇。
- 不要用 Downvote 表达"这个方向我不看"——那是主题权重该做的事，在 `/profile` 里调。混用会让
  单篇惩罚淹没在噪声里。
- 一周看一次 `/profile`：`output/profile_state.json` 里的主题倍率会告诉你画像被你的行为带向了哪。
  `python profile.py` 可以直接打印当前倍率与关键词两端极值。
