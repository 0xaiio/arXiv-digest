arXiv 论文日报

通用版：抓哪些分类由你决定，默认不预设任何研究领域。

👋 还差一步：选择要跟踪的 arXiv 分类

本工具不再内置固定的分类（旧版的 cs.DB / cs.DC / cs.FL / cs.LO / cs.PL / cs.SE 只是一份个人示例配置，默认不加载）。请先挑出你关心的分类，之后每天的日报就按它们抓取。

  1. 1
    打开「⚙ 画像与设置 → 🗂 arXiv 类别」
    两个联动下拉框：先选主类（abc，如 cs），再选子类（def，如 DB）； 都支持搜索与多选。选好的分类以标签形式排列，可拖拽排序（顺序 = 摘要页分类小节的顺序）， 点标签上的 × 删除。
  2. 2
    回到命令行重新运行 python run_daily.py
    新增分类要重新抓取才会出现论文。想先看一份现成的六分类示例： python tools/preset.py import hengxin（导入后同样要重跑）。
前往选择类别 →
共收录 %(total)d 个官方分类，来自 arxiv.org/category_taxonomy（%(version)s）。 分类示例：%(samples)s
选完类别后本页会自动被替换成当期日报。收藏 / 下载 / Downvote 记录保存在 output/library.json。
